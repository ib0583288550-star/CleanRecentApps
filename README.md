# ניקוי מהיר — yb apps

מודול LSPosed/Xposed שמטרתו להוסיף כפתור **ניקוי הכל** למסך האפליקציות האחרונות.

## יעד
- Android 10 (API 29)
- Android 13 (API 33)
- מכשירים עם Root ו-LSPosed

## מצב הפיתוח
הגרסה הנוכחית כוללת מסך הגדרות בעברית לשמירת מיקום אופקי, מיקום אנכי וגודל הכפתור, וכן אבחון של תהליך SystemUI והמפעיל כדי לזהות את מחלקות מסך האפליקציות האחרונות. האבחון נדרש משום שמסך Recent Apps משתנה בין יצרנים וגרסאות Android.

**חשוב:** כפתור ניקוי הכל עדיין לא מוזרק למסך Recent Apps. יש להתאים את ההזרקה למחלקה שתזוהה ביומני LSPosed ולבדוק אותה במכשיר לפני שימוש.

## בנייה
GitHub Actions בונה APK של מודול Xposed ומעלה אותו כ-artifact.

## התקנה ואבחון
1. התקן LSPosed במכשיר והתקן את ה-APK.
2. הפעל את המודול עבור SystemUI ועבור המפעיל הרלוונטי (במכשיר עם Smart Launcher, הפעל גם עבור Smart Launcher אם הוא מופיע ברשימה).
3. אתחל את המכשיר, פתח את מסך האפליקציות האחרונות, ואז בדוק ביומן LSPosed הודעות שמתחילות ב-`CleanRecentApps:`.
4. יש להשתמש בשמות המחלקות שמופיעים ביומן כדי להשלים התאמה למכשיר.

קרדיט: **yb apps**
