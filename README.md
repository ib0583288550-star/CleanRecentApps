# ניקוי מהיר — yb apps

מודול LSPosed/Xposed שמטרתו להוסיף כפתור **ניקוי הכל** למסך האפליקציות האחרונות.

## יעד
- Android 10 (API 29)
- Android 13 (API 33)
- מכשירים עם Root ו-LSPosed

## מצב הפיתוח
נוספה לאפליקציה מסגרת הגדרות בעברית לשמירת מיקום אופקי, מיקום אנכי וגודל הכפתור. בשלב זה ההגדרות נשמרות באפליקציה, אך עדיין לא מחוברות לרכיב שמוזרק למסך Recent Apps. שילוב הכפתור עצמו תלוי בגרסת SystemUI/Launcher של יצרן המכשיר, ולכן נדרש להתאים ולבדוק כל מכשיר בנפרד לפני שמכריזים על תמיכה מלאה.

## בנייה
GitHub Actions בונה APK של מודול Xposed ומעלה אותו כ-artifact.

## התקנה
1. התקן LSPosed במכשיר.
2. התקן את ה-APK והפעל את המודול עבור SystemUI/Launcher לפי ההוראות.
3. אתחל את המכשיר ובדוק את מסך האפליקציות האחרונות.

קרדיט: **yb apps**
