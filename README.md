# ניקוי מהיר — yb apps

גרסה ללא Root וללא LSPosed. משתמשת בשירות הנגישות של Android כדי לזהות את מסך האפליקציות האחרונות ולהציג עליו כפתור צף.

## הפעלה
1. התקן את ה־APK ופתח את האפליקציה.
2. לחץ על **הפעלת השירות ללא LSPosed**.
3. במסך הנגישות בחר **ניקוי מהיר** והפעל את השירות.
4. פתח את מסך האפליקציות האחרונות.

## הערות
- Android מחייב הפעלה ידנית של שירות הנגישות.
- הכפתור מזוהה לפי שמות חלונות Recents/Overview, ולכן ייתכן שנצטרך להתאים את הזיהוי לממשק של יצרן המכשיר.
- בלחיצה השירות ינסה למצוא כפתור מערכת Clear all/נקה הכל. אם אינו קיים, הוא ינסה לסגור כרטיסים במחוות החלקה.
- נדרשת בדיקה במכשיר; ממשקי Recents שונים בין יצרנים.

קרדיט: **yb apps**
